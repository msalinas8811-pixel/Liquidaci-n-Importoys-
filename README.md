# Control de Ventas y Liquidación — Importoys El Salvador

Aplicación web progresiva (PWA) para registrar ventas, gastos, inventario y consultar reportes/liquidación por empresa.

## Archivos principales
- `index.html`: interfaz y lógica de la aplicación.
- `manifest.webmanifest`: configuración PWA.
- `sw.js`: service worker.
- `icons/`: iconos de la aplicación.
- `LEEME.txt`: instrucciones originales del proyecto.

## Ejecutar localmente
1. Descargá o cloná el repositorio.
2. Abrí `index.html` en un navegador para una revisión básica.
3. Para probar correctamente la PWA y el service worker, serví la carpeta mediante HTTPS o un servidor local.

## Publicar en GitHub Pages
1. Creá un repositorio en GitHub.
2. Subí el contenido de esta carpeta a la raíz del repositorio.
3. En **Settings → Pages**, elegí la rama principal y la carpeta `/ (root)`.
4. Guardá y esperá la publicación; GitHub mostrará la URL del sitio.

## Importante
- Esta versión conserva el proyecto web existente y añade documentación para GitHub.
- No contiene credenciales ni configuración de servicios externos.
- Antes de usarla como sistema de registros oficial, verificá los cálculos de liquidación y respaldá tus datos.
